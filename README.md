# বাজার দর | BazarDor

**নিত্যপ্রয়োজনীয় পণ্যের দাম এক নজরে।**

BazarDor is a Bengali-first market-price dashboard for browsing everyday product prices, comparing market ranges, and seeing which prices are rising or falling.

## Technologies

- **Next.js 16** — App Router and server-rendered pages
- **React 19** and **TypeScript**
- **Tailwind CSS 4** and **daisyUI**
- **Better Auth** — email/password and optional Google and GitHub sign-in
- **MongoDB** — user, account, and session persistence
- **Programming Hero BazarDor API** — category and product market data
- **React Hot Toast** — feedback and notifications

## Key features

1. **Market price dashboard** — browse current prices for everyday products and see recent price changes.
2. **Category browsing and sorting** — explore products by category and sort them by price.
3. **Market comparison** — view minimum, maximum, and average prices across markets for each product.
4. **User accounts and profile management** — sign up or sign in with email and password, optionally use Google or GitHub, and update your profile name.
5. **Responsive, accessible experience** — loading skeletons, helpful not-found pages, and clear authentication notifications.
